Surviving the Titanic!

Todd K Hartman

Last updated 2024-04-24

For today’s lab, we’re going to use a famous dataset and example, namely surviving the Titanic disaster. As you might have guessed, we’re going to model factors that might help us understand why some passengers survived while others did not. Many datasets about the sinking of the Titanic are available online, but we’re going to use the one from Kaggle, which is a popular data science website.

The Titanic data can be found here: (https://www.kaggle.com/c/titanic)[(https://www.kaggle.com/c/titanic)].

Data Dictionary
Variable Definition

parch Number of parents / children aboard
ticket Ticket number
fare Passenger fare
cabin Cabin number

Now we should check to see if there are any missing variables in the outcomes or predictors that might cause problems with our analyses.

## Are there any missing values among potential predictors?
train %>%      # Pass the 'train' data to...
  is.na() %>%  # Find any missing values
  colSums()    # Sum NAs by columns

Hmmm…there appears to be many missing values for age (nearly 20% of cases!), which we might expect to be related to survival rates. From survivor accounts, we know, for example, that women and children were given priority for lifeboats; hence, they should be more likely to survive this disaster. Without a predictor variable for age, we might be missing a potentially important explanatory variable for Titanic survival rates. Of course, we could opt to delete these missing values, but that would be a waste of potentially valuable information for our model (cases in our model will be removed via listwise deletion).

Instead, we can use the ‘mice’ package to impute missing values for age. This package uses a technique called predictive mean matching (PMM) to fill in missing values based on values of other variables in the dataset. For example, suppose that we wanted to impute missing values for someone’s vote choice in a previous election. We could use what we know about their age, gender, and education to fill in these missing values for their vote choice. In the case of the Titanic dataset, we have less information available, but we can still try to use available data about a passenger’s class, fare, etc. to fill in missing values for their age.

Before we do that, however, we should create other variables that might be useful for our model. For instance, we need to dummy code the Sex variable, which is currently measured as a nominal variable. We can do this by creating a new variable called female that is equal to 1 if the passenger was a woman and 0 otherwise. We can also generate dummy variables for the Pclass indicator, by creating two new variables called first.class and second.class that are equal to 1 if the passenger was in first or second class, respectively, and 0 otherwise.

We also might want to create a variable that indicates whether a passenger was traveling with family. We can do this by creating a new variable called ‘family’ that is equal to 1 if the passenger had any siblings or parents on board and 0 otherwise.

## Create dummy variables for gender and class
train$female <- ifelse(train$Sex == 'female', 1, 0)
train$first.class <- ifelse(train$Pclass == 1, 1, 0)
train$second.class <- ifelse(train$Pclass == 2, 1, 0)

## Create 'family' variable to test whether having family on board 
## impacted survival rates. Use the double pipe operator from 'magrittr' 
## package, which passes data but also overwrites data with subsequent operations
train %<>%                                 # %<>% is the same as: train2 <- train2 %>%)
  mutate(                                         # Add variables to existing dataset
    family = ifelse(SibSp > 0 | Parch > 0, 1, 0)  # If passenger has any family on board
  )

Let’s now impute age based on several other predictor variables.

## We can use the 'mice' package to IMPUTE (i.e., fill in) missing values for age
## But let's not use all variables for this imputation process;
## Some variables are not helpful or analysable (e.g., PassengerId, ticket, etc.)

## Create a list of formulas for imputation needed for the 'mice' package
## Here we're specifying that age is a function of class, siblings, parents, and fare
form <- name.formulas(list(Age ~ female + first.class + second.class + family + Fare))

## Impute missing values for age using the 'mice' package
train.imputed <- train %>%
  select(Survived, Age, female, first.class, second.class, family, Fare) %>%
                      mice(              # Function
                      formulas = form,   # Variables to use for imputation
                      meth = 'pmm',      # Predictive mean matching
                      m = 10,            # Number of samples
                      maxit = 100,       # Maximum # of iterations
                      seed = 8675309     # For replication purposes
                      )

Now we’re ready to fit a logistic regression model to the Titanic data. We’re going to use the ‘glm()’ function from the ‘stats’ package to fit a logistic regression model to the data. The logistic regression model is a type of generalized linear model (GLM) that is used to model binary outcomes. In this case, we’re going to model the probability of survival as a function of several predictor variables.

## Fit a Logistic Regression
log.fit <- glm(Survived ~ female + Age + first.class + second.class + family + Fare, 
               family = "binomial", 
               data = train2)

The results above suggest that gender, age, and ticket class are statistically significant. Remember that interpretting logistic regression coefficients is difficult because they are in log-odds units. To make the coefficients more interpretable, we can exponentiate them to obtain odds ratios. What do you see?

Another way of interpretting the logistic regression coefficients is to calculate predicted probabilities of survival for different values of the predictor variables. We can do this by using the ‘predict()’ function from the ‘stats’ package. This function calculates the predicted probabilities of survival based on the logistic regression model we just fit. We can then use these predicted probabilities to calculate the average predicted probability of survival for different values of the predictor variables.

To create predicted probabilities we need to create a new data frame with the values we want the independent variables to take on to create our predictions.

## Predicted probabilities of survival
## Make predictions from logistic regression model, check accuracy
train2$prob <- predict(log.fit,  # Predicted probabilities from model
                       newdata = train2,   # based on train2 dataset
                       type = "response")  # using responses

summary(train2$prob)  # Check predicted probabilities of survival range from 0 to 1
##    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
## 0.02093 0.10230 0.27816 0.38384 0.63341 0.97092
## Now create a new data frame with the values we want the independent variables to take
## on to create our predictions; let's start with predicted probabilities for female
## passengers in first class who are traveling with family members
new.df <- with(train2, 
  data.frame(female = c(0,1),        # Vary female dummy variable
             Age = mean(Age),        # Use mean age for predictions
             first.class = c(1,1),   # Set first class to 1
             second.class = c(0,0),  # Set second class to 0
             family = c(1,1),        # Set family to 1
             Fare = mean(Fare) )     # Use mean fare for predictions (might be wrong b/c first class chosen)
  )

## View data frame
new.df
## Calculate predicted probabilities of survival based on new data frame
new.df$prob <- predict(log.fit, newdata = new.df, type = "response")

## View predicted probabilities (i.e., predicted survival by )
new.df

In the above example, the predicted probability of survival is above .90 for women in first class who are traveling with family members (and who paid an average fare). This is a very high probability of survival, which is consistent with survivor accounts of the Titanic disaster. For men, this probability of survival drops below .5 (a 50-50 chance of survival!).
